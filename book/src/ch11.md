# 第 11 章：Validation：停止不等于完成

**状态：已实现并验证。** M7 提供确定性 Validator、ValidationReport 和 finish gate；它不替代领域验收、测试系统或真实 artifact 检查。

## 11.1 ModelFinished 只是一个候选状态

模型返回 final text 只说明模型停止生成。Run 只有在 Validator 的所有检查通过后才能进入 Completed；失败必须保留每项 name、code 和 message。

~~~python
validator = Validator({"nonempty": lambda value: bool(value)})
report = validator.validate("answer")
terminal = finish(report)
assert terminal["status"] == "Completed"
~~~

ValidationReport.passed 对空检查集 fail closed。成功路径是所有检查通过；重要失败路径是一个检查返回 false，以及检查抛出异常。异常会变成 validator_error，而不是让进程崩溃或让模型文本直接获准。

## 11.2 聚合、证据和边界

Validator 按名字排序，确保报告确定性；digest 可供下一章 Evidence 和 ReviewBundle 引用。Validation 是判断，Evidence 是支持判断的材料，两者不混为一类。
