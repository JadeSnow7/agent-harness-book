# 第 10 章：Policy 与 Sandbox

**状态：设计骨架/尚未实现。** 本章定义 M6 的 allow/deny/ask 和 sandbox 边界；P0 的 `AllowListPolicy` 只是确定性参考。

M2 的工具 allowlist 能表达“这个名字可用”，但它不等于完整权限系统。`AllowListPolicy` 是 P0 的确定性最小实现，不是 production Policy Engine；路径检查也不等于 OS 沙箱。

## 10.1 学习目标

完成本章后，读者应能把审批决定绑定到具体 ChangeSet，证明拒绝发生在工具执行前，并解释参数检查、Workspace 边界和 OS 隔离分别覆盖什么风险。

## 10.2 决策发生在哪里

工具调用应经过：

```text
ToolCall → Policy: Allow / Deny / Ask
         → Runtime → Environment
```

Policy 读取调用、身份、当前 Run 和风险上下文，返回结构化决定；它不执行工具。P0 选择 Deny terminal，暂不实现人工 Ask。后续 Ask 必须有等待状态和超时，不能把“没有回答”当成 Allow。

```rust
enum Decision { Allow, Deny { reason: String }, Ask { approval_id: String } }
```

规则应尽可能是默认拒绝、最小能力、明确资源范围。`bash` 的程序名 allowlist 只能限制启动入口；若允许解释器，解释器内部仍可能绕过文件规则。

## 10.3 Sandbox 的层次

从弱到强可以依次讨论：工具参数检查、workspace 路径边界、环境变量过滤、进程隔离、容器/虚拟机和操作系统权限。每层减少一种风险，没有哪一层自动覆盖全部风险。TOCTOU、symlink、挂载点、网络和子进程都要单独建模。

不要把提示词“不要删除”写成安全保证。提示词属于意图，Policy 和 Sandbox 才属于执行边界。

## 10.4 验证

策略测试至少断言：被拒绝调用没有 `ToolStarted`；未知工具不会绕过策略；路径逃逸被拒绝；审批 id 只对应一个 ChangeSet；诊断不包含 Authorization Header。默认测试不访问真实网络，也不启动危险进程。跨平台故障用 failpoint。

当前 P0 参考组合：

```text
ScriptedMockModel → AllowListPolicy → ToolRegistry
                              ↘ EventLog
```

验证场景：被拒绝调用没有 `ToolStarted`；未知工具不能绕过策略；路径逃逸被拒绝；审批 id 只对应一个 ChangeSet；诊断不包含 Authorization Header。默认测试不访问真实网络，也不启动危险进程。

## 10.5 本章将得到什么

完成 M6 Policy 与 Sandbox 后，系统将拥有模型之外的执行前决定和分层资源边界；这仍不等于生产级 OS 隔离或完整人工审批 UI。

下一章处理最后一个容易被忽略的断言：模型说“完成”，为什么不能直接把 Run 标成 Completed。

## 10.6 能力清单不等于安全边界

本章把执行前决定从 Tool Runtime 中外置，收益是拒绝可以发生在 `ToolStarted` 之前，并且 allow/deny/ask 能与具体 `call_id`、Run 和 ChangeSet 绑定。参数校验、Workspace 边界和 OS 隔离各自覆盖不同风险，读者因而可以检查“这一层到底防住了什么”，而不是把一个 allowlist 称为完整沙箱。

代价是 Policy 与 Sandbox 之间不能互相冒充。Policy 规则可能漏掉资源范围，路径检查可能被 symlink 或 TOCTOU 绕过，进程隔离又可能遗漏网络、环境变量和子进程。Ask 状态还引入等待、超时和拒绝后的终止语义。对 AI 系统而言，工具描述和返回值本身也可能携带 prompt injection；模型被允许看到能力，不代表它被允许使用能力。

| 能力 | 当前状态 |
| --- | --- |
| P0 `AllowListPolicy`、终端拒绝和“拒绝不启动工具”测试 | P0 参考实现，已验证 |
| 与 ChangeSet 绑定的 Allow/Deny/Ask | 设计骨架/尚未实现 |
| OS 级 Sandbox、审批 UI、网络和 symlink 全面防护 | 尚未实现 |

当前成熟度是 **Prototype（确定性 allow/deny 范围内）**：P0 已证明一个重要不变量，但没有生产级隔离证据。这里有意留下的技术债是暂不实现人工 Ask 和真实危险进程；默认拒绝、无网络测试和 failpoint 让教学路径可控。下一章必须继续收紧完成语义：即使 Policy 允许动作，模型的 final answer 仍只是声明，环境检查才能决定任务是否完成。
