# P0：确定性最小闭环

P0 的 Rust 组合位于 `examples/rust/p0-demo`。它将 `DeterministicRunner` 与 `ScriptedMockModel`、`SimpleContextBuilder`、`AllowListPolicy`、`ToolRegistry`、`RequiredOutputValidator` 和 `InMemoryEventStore` 连接起来。

一次成功运行的主要事件顺序是：

```text
RunStarted
→ ModelInputBuilt → ModelActionReceived
→ PolicyEvaluated → ToolStarted → ToolFinished
→ ModelInputBuilt → ModelActionReceived
→ ValidationCompleted → EvidenceRecorded → OutcomeRecorded
```

Policy 拒绝发生在工具执行之前，因此拒绝路径没有 `ToolStarted` 或 `ToolFinished`。工具失败是结构化 `ToolResult`，而模型错误、上下文错误、事件写入错误和验证器错误会产生结构化失败结果。事件序号从 0 连续递增，`EventId` 由 `run_id:sequence` 确定生成。

运行示例：

```bash
cargo run -p p0-demo
cargo test -p p0-demo
```

P0 仍是内存、单进程、无外部副作用的实验性实现；它不提供生产级崩溃恢复、Exactly-once 外部副作用、真实 Provider、流式响应或并行工具调用。
