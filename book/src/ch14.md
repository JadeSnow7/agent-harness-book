# 第 14 章：受控委派：SubRun 不是另一个 while

**状态：已实现并验证。** M9 的 SerialDelegateExecutor 只演示父子身份、能力和预算字段；没有并行调度或真实外部 coding agent。

## 14.1 委派合同

TaskSpec 包含 task_id、parent_run_id、goal、capabilities 和 budget；SubRun 分配独立 run_id；TaskResult 包含结构化文本和 evidence。子运行不能使用父运行的 run_id，也不能返回没有证据的“成功”。

~~~python
spec = TaskSpec("child", "parent", "inspect", frozenset({"read"}), 2)
executor = SerialDelegateExecutor(
    lambda task, run: TaskResult(task.task_id, run.run_id, True, ("e1",), "ok")
)
results = executor.run("parent", [spec])
aggregate("parent", results)
~~~

成功路径是 serial child 返回带证据的结果；重要失败路径是 parent identity 不匹配、child result identity 不匹配、能力超出授权、budget 超限、空 evidence 或空聚合。聚合失败不会被包装成成功。
