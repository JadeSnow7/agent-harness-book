# 第 13 章：Loop 收敛：继续、停止还是升级

**状态：已实现并验证。** M9 的 StopPolicy、ProgressOracle 和 Runner 提供有界离线循环；它不启动真实外部 Agent。

## 13.1 循环需要明确的停止语言

ProgressOracle 记录 steps、tools、最近观察和重复次数。StopPolicy 区分 CONTINUE、COMPLETED、BUDGET_EXHAUSTED、STALLED、ESCALATE 和 CANCELLED，并在下一次模型调用前检查取消与预算。

~~~python
oracle = ProgressOracle(5)
oracle.observe("same")
oracle.observe("same")
oracle.observe("same")
assert StopPolicy().decide(oracle) == StopReason.STALLED
~~~

成功路径是模型给出候选工具后继续；重要失败路径是重复动作导致停滞，以及达到步数/工具预算。Runner 还把 provider error、duplicate call_id 和 policy escalation 变成结构化 RunResult。

## 13.2 Model action、工具结果与终态

Runner 的每次请求、响应、工具开始、工具结果和终态都可写入 EventLog。工具 schema 失败不会调用 handler；effect 工具在 policy 后先进入 IdempotencyLedger。最终文本仍要经过 Validator，不能因为模型说“完成”就直接 Completed。
