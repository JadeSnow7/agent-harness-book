# 第 15 章：Extension：能力声明与生命周期

**状态：已实现并验证。** M10 的 FakeMCP、FakeSkill、FakeHook、FakePlugin 和 CapabilityManifest 是离线扩展边界；它们不是插件 sandbox、供应链验证或外部连接。

## 15.1 Manifest 先声明能力

CapabilityManifest 记录 name、version、source、capabilities 和 schema，并提供 fingerprint。重复扩展 identity 在 compose_profile 中拒绝；manifest schema 错误在 invoke 前拒绝。

~~~python
manifest = CapabilityManifest("fake", "1", "demo",
                              frozenset({"read"}), {"type": "object"})
extension = FakeMCP(manifest)
extension.activate()
value = extension.invoke({"ok": True})
~~~

## 15.2 生命周期不是权限替代品

REGISTERED、ACTIVE、REVOKED、FAILED 控制扩展是否可调用。未 ACTIVE 调用、timeout 非法值和 schema 错误都会失败。ExtensionGateway 再把 policy allow、Validator 和 EvidenceStore 接到扩展输出上；扩展本身不能绕过这些边界。

成功路径是 active fake adapter 返回脱敏结果；重要失败路径是未激活、撤销后调用和 manifest payload 错误。正 timeout 在本切片只作为调用参数检查，不是线程级超时证明。
