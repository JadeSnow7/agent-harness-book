# 第 12 章：Evidence 与 Observability：让结论可复查

**状态：已实现并验证。** M8 提供 Evidence、EvidenceRef、Trace、Summary、ReviewBundle 和只读投影；它不是完整 tracing、指标系统或机密管理器。

## 12.1 Evidence 必须能指回事实

Evidence 有 evidence_id、run_id、kind、value 和 supporting_events。project_evidence 会检查引用的 seq 存在且属于同一 Run；EvidenceStore 在保存时做深层脱敏。Trace 只读投影事件，Summary 只组合已有 Evidence。

~~~python
event = EventEnvelope(1, "tool.result", identity, {"ok": True})
evidence = Evidence("e1", "run-1", "tool", {"api_key": "secret"}, (1,))
safe = project_evidence(evidence, [event])
assert safe.value["api_key"] == "[REDACTED]"
~~~

成功路径是引用存在的事件；重要失败路径是缺失 seq 和跨 run 引用。Authorization、Bearer token、绝对宿主路径在 Evidence 和只读 trace 投影中都不应泄露。

## 12.2 ReviewBundle 绑定审查摘要

ReviewBundle.bind 将 ChangeSet、ValidationReport 和 Evidence 的 digest 绑定起来。三者任一内容变化，bundle_digest 都变化；Approval 只能绑定同一组摘要。Observability 查询不修改 EventLog 或 RunOutcome。

~~~python
bundle = ReviewBundle.bind(change, report, [safe])
assert bundle.bundle_digest
~~~
